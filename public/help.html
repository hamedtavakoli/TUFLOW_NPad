Quick start

  1. Select Choose Root in the Project Files panel and choose the model folder that contains your TUFLOW inputs.
  2. Use Open to load one or more control/support files, or use New to start a new file.
  3. Edit with syntax highlighting, autocomplete, formatting, active-line command help, and diagnostics.
  4. Use Check References after choosing a Project Root to validate referenced file paths.
  5. Review issues in Diagnostics; select a problem row to jump to that line.
  6. Use Save to download the active file, or Export to download diagnostics.

Best first action

Choose the Project Root before running reference checks. Without an indexed root, TCS can still edit files, but it cannot confirm whether referenced project files exist.

Workspace layout

Top toolbar

Create, open, save, undo, redo, toggle theme, compare files, check references, format the active file, and export diagnostics.

Shows help for the active line and includes the searchable command library.

Diagnostics

Lists validation and reference-check messages for the active file.

Files and tabs

  • New creates an editable untitled TUFLOW control-style file.
  • Open loads one or more readable project files into tabs.
  • Save downloads the active tab content using the tab name.
  • Dirty markers identify tabs with unsaved changes.
  • Each tab keeps its own cursor, selection, scroll position, and undo/redo state.

Editing support

  • Autocomplete suggests known TUFLOW commands and project inputs while typing.
  • Format File is available for TUFLOW editor files and normalises command layout.
  • Search in the editor helps locate text in the active tab.
  • Undo/Redo buttons apply to the active tab.
  • Dark/light mode follows the toolbar toggle and is saved in the browser.

Autocomplete tip

Use autocomplete to reduce command spelling mistakes. If a command is not recognised, check the Command Library for current and legacy command names.

Project Root and Project Files

The Project Root is the folder TCS uses as the reference point for file availability checks.

  1. Click Choose Root and select the model root folder.
  2. TCS indexes files and folders, excluding common result/log/check folders by default.
  3. Use Refresh after changing files outside the browser.
  4. Use the search box, type filter, extension filter, tree view, and type view to find files quickly.
  5. Open indexed files directly from the panel when the browser provides file access.

Browser access note

Folder and file access depends on browser capabilities and permissions. If direct folder access is unavailable, use the file picker fallback to select project files.

Reference checks and diagnostics

  • Check References validates the active file and checks referenced paths against the indexed Project Root.
  • The Reference Checks toggle controls whether file availability messages are shown.
  • Select a diagnostics row to jump to the related line in the editor.
  • Export downloads the current diagnostics so they can be shared or reviewed outside the app.
StatusMeaning
AvailableThe referenced path or file name was found in the Project Root index.
MissingThe reference was checkable, but no matching indexed file was found.
ExcludedThe path is inside an excluded folder such as results, logs, or checks.
UncheckableThe reference contains variables, wildcards, or placeholders that cannot be resolved statically.

Command Guide and Library

  • Line Guide shows syntax, summary, expected value details, and documentation links for the command on the active line.
  • Library lets you search all loaded commands.
  • Filter the library by category and by current/legacy command status.
  • Use documentation links for deeper TUFLOW reference material when available.

Compare mode

Use Compare to review differences between two open tabs or pasted text.

  • Choose left and right sources from open tabs, or select manual paste.
  • Use Previous and Next to move between changes.
  • Use Swap to reverse sides and Clear to reset manual content.
  • Turn on ignore options for blank lines, extra spaces, case, comments, or unchanged lines.
  • Scroll is synchronized between the left and right result panels.

Shortcuts and tips

  • Tab accepts the selected autocomplete suggestion.
  • ArrowRight accepts the next word of a selected autocomplete suggestion.
  • Save often by downloading the active tab after important changes.
  • Refresh the Project Root index after adding, renaming, or deleting files outside TCS.
  • Use Compare before and after formatting if you want to review formatting-only changes.

Troubleshooting

Reference checks show missing files

Confirm the correct Project Root is selected, refresh the index, and check whether the file is inside an excluded folder or uses variables/wildcards.

Command help is empty

Command help is available for recognised TUFLOW control-file commands. Check spelling, remove leading comments, or search in the Library.

Format File is disabled

Formatting is only enabled for TUFLOW editor-language files. Plain text and batch files can still be edited and saved.

Project files cannot open from the panel

Your browser may not expose direct file handles for that selection. Use the Open button to load the file manually.
